# Django Blog Application

A dynamic blog application developed using Django framework.

## Features

- Create blog posts
- View all posts
- Edit existing posts
- Delete posts
- Responsive UI
- Admin panel support

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## Installation

```bash
git clone <repository-link>
cd django-blog-app
pip install -r requirements.txt
python manage.py runserver
```

## Output

The application allows users to perform full CRUD operations on blog posts.
